# Movie Shelf

Movie Shelf is a simple movie-browsing website built to make choosing a film
for movie night easier. Visitors can explore a curated collection, search by
title, release year, or genre, and save movies they want to revisit.

## What you can do

- Browse movie details, including release year, genre, description, and poster.
- Search the collection by title, year, or genre.
- Add movies to or remove movies from a personal Favorites page.
- Keep favorites saved in the current browser using local storage.
- View information about the project and its developer on the About page.

The collection is maintained in `src/data/movies.json`, so movie information
can be updated alongside the application.

## Built with

- React
- JavaScript
- Vite
- HTML and CSS

## Run locally

From the `frontend` directory, install dependencies and start the development
server:

```bash
npm install
npm run dev
```

To create a production build or run the linter:

```bash
npm run build
npm run lint
```
